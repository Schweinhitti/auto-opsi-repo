## Problems found and corrected

Real tests exposed cross-device hard-link failure between Docker bind mounts during metadata staging, current upstream asset/type changes, vendor CDN redirects, Adoptium version normalization, a PowerShell output/return-code interaction, and Audacity's filename/length/SHA256 checksum table. Each was corrected or explicitly disabled before final validation. Official Git installer source and Microsoft's Python manifest also confirmed special registry naming/version conventions; Git, Python and Temurin have explicit version mappings at revision 2. Pytest initially discovered tests inside OPSI's extracted runtime cache; `pytest.ini` now restricts collection to this project's tests.

Repeated live validation reached GitHub's unauthenticated hourly rate limit. The builder recorded failures, continued other products and retained existing archives. A later run after GitHub's reported reset completed with zero failures. Subsequent packaging refinements encountered the hourly limit again; final Git/Python revision 2 packages therefore reuse their independently reverified existing payloads. No token was configured and no GitHub HTML scraping or rate-limit circumvention was used.
